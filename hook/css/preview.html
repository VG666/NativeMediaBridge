视频条（直角 · 压在画面底边）

盒子 16:9；条宽 = 盒子宽、贴在盒子底边内侧（这两句由 CSS 保证）。 宽 <300 加 data-nmb-narrow，<240 再加 data-nmb-tiny（拖上面的"元素盒子宽"看档位切换）。 本页的条在盒子里，滚动时由浏览器自然裁切；运行时"被裁掉一点就整条不显示"是 placeBar 的显隐策略，本页不演示（要看那个口径用真机的 tests/testjs/_nmb_ui_lock.html）。

本页复刻了什么、没复刻什么

  • 复刻（都是 css 能决定的部分）：控件的 DOM 结构与 data-* 标记、条贴盒底内侧、宽度 = 盒子宽、音频 fill 撑满盒高、宽度分档（narrow/tiny）、进度条三段色带（走与运行时同款的"伪元素规则"机制，见下方脚本注释）、记号的三角/双竖条。
  • 本页用 CSS 定位：条是盒子的子元素，position:absolute;left:0;right:0;bottom:0。尺寸一变就重判档位靠 ResizeObserver，进度/时间靠滑块事件 —— 没有按帧循环，空闲时页面零改动。
  • 没复刻：原生视频帧与"挖洞"合成（这里画面只是色块）、真实播放状态、placeBar 的显隐口径（元素被裁掉一点就整条不画）。
  • 要看真机效果：编译后用 tests/testjs/_nmb_ui_lock.html 之类页面跑 tests/test_bindwebview.py。
