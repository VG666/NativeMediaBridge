控件条 · 独立编辑页

控件条的样式全部内联在本文件的 style id="nmb-css" 里，分成三段、分别对应项目里的 三份真源：hook/css/base.css、tier.css、audio.css。直接改、按 F5 看效果。
  1. 改完写回项目：python utility/_nmb_css_page.py
  2. 写回并生成 + 编译：python utility/_nmb_css_page.py --gen --build
  3. 只想看会改哪些行：python utility/_nmb_css_page.py --dry
  4. 反过来（改的是 hook/css/*.css，要同步回本页）：python utility/_nmb_css_page.py --to-html
只认 NMB-EDIT-BEGIN / NMB-EDIT-END 标记之间夹着的内容，标记行别动。 本页的条结构是 hook/js/injection.js 里 buildBar 的镜像， 改结构（增删控件、改 data-* 名）请同步改 buildBar。

本页复刻了什么、没复刻什么

  • 复刻（css 能决定的部分）：控件 DOM 与 data-* 标记、条贴盒底内侧、宽度 = 盒子宽、音频 fill 撑满盒高、分档（narrow/tiny）、进度条三段色带、记号的三角/双竖条/放大括号。
  • 没复刻：原生视频帧与"挖洞"合成（这里画面只是色块）、真实播放、placeBar 的显隐口径（元素被裁掉一点就整条不画）、自动淡出计时。
  • 要看真机效果：编译后用 tests/test_bindwebview.py 跑真实内核截图。
